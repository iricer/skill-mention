# 按投稿模板撰写论文

根据用户提供的投稿模板、已有研究材料和指定页数，生成可继续编辑的论文初稿。

使用 `ai-research-writing`。读取我本次提供的投稿模板、论文摘要或大纲、项目资料、实验结果和指定图表。投稿模板由我在每次使用时提供。如果我尚未提供模板，先请我补充模板。

1. **按我指定的页数规划全文。** 本次页数要求为 **[填写目标页数、页数范围或上限]**。写作前据此分配各节篇幅，并预留图表、公式及其他计入总页数的内容所需空间。排版后以投稿模板中的实际页数为准，通过调整各节内容的详略达到要求。
2. **以投稿模板为排版依据。** 沿用模板的纸张尺寸、分栏、字体、标题层级、图表题注和公式编号方式。按我的要求保留指定区域。尚未提供的作者、单位、稿件编号等信息保留模板占位。
3. **以研究记录为内容依据。** 围绕已完成的研究组织摘要、引言、方法、实验、结果与结论。数学模型和算法公式以设计记录为依据，并与实际运行的代码、模型和配置核对。若早期方案与正式实验不同，正文以正式实验为准。实验条件、数值和结论应能追溯到项目记录。
4. **使用指定的图表和素材。** 按我指定的文件版本和顺序插入图表，编写对应的图题、表题和正文说明。参考文献按本次要求处理。
5. **统一公式格式和符号。** 对 Word 稿件，编号公式、行内公式和数学符号都使用模板对应的可编辑公式方式。统一正文、编号公式、符号表和参数表中同一物理量的写法。
6. **核对后交付。** 检查正文与实验记录的一致性，以及实际页数、公式显示、图表可读性和跨页排版。按指定语言、文件格式和目录交付稿件，并告知实际页数。
