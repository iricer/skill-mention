# 0001 绘制论文流程图

根据用户提供的论文、摘要、项目资料或方法描述，绘制适用于科研论文的方法流程图。绘制前查看[风格示例图](../../assets/0001/paper-flowchart-example.png)；需要理解本例技术背景时再读[实例说明](example.md)。

## 输入

- 论文或方法资料：以用户本次提供或明确指定的资料为准。
- 风格示例：默认使用本条目收录的图片；用户另给示例或偏好时以本次要求为准。
- 输出语言：默认英文。
- 输出目录：使用用户指定路径；未指定时选择当前项目的合适图片目录并告知位置。
- 特殊要求：画幅、用途、尺寸、输出格式等按本次要求确定。

只有缺失信息会实质改变研究逻辑时才询问；普通配色、对齐和留白由绘图者合理决定。

## 通用提示词

请根据本次论文资料绘制科研方法流程图，并把所附示例图作为视觉风格参考。

### 内容与结构

1. 先识别研究目标、输入、主要方法、步骤顺序、并行关系、分支、反馈循环及输出，再确定框图结构。必要时在任务内部整理节点和连线清单。
2. 阶段数量、框的数量、大小和位置由本次研究内容决定。示例只提供风格，不是固定布局模板。
3. 保留关键技术关系，压缩冗长表述，不为排版增加不存在的步骤、判断、反馈或研究结论。
4. 准确表达执行主体和职责；论文涉及人工、AI、数值算法、试验或仿真时，按事实区分。不要把计划开展的验证写成已完成的结果。
5. 方法名、数值、单位与缩写以本次资料为准，不沿用示例中的控制器名称、阶段数、搜索预算或对象类型。

### 视觉风格

1. 白色背景、简洁学术风格，参考示例采用低饱和浅桃色、浅绿色、浅黄色、浅青色及淡紫色。
2. 颜色用于区分阶段或功能，不机械绑定固定阶段。保持充分对比，正文为清晰黑字。
3. 以细灰色或深灰色边框的矩形为主，最终输出可用圆角矩形；循环或子流程可用虚线分组框。存在实际判断时才采用判断菱形。
4. 英文使用 Times New Roman 或相近衬线字体，重要阶段和模块标题适当加粗。文字简短、分行自然，不挤出框外。
5. 根据内容选择纵向、横向或混合布局。主要阶段可在左侧编号，反馈和辅助信息可放侧边；不照搬示例的框数或位置。
6. 空心下箭头可用于阶段间过渡，普通细箭头用于具体顺序、信息流与反馈。图形选择服务于真实含义。
7. 字号协调、对齐整齐、框内留白充分、边缘安全，不添加水印、无关装饰或虚假结果图。

### 连线与逻辑

1. 具体流程箭头应有明确起点、终点及方向，并连接相应节点边缘。不能悬空停在框之间，或误连到旁注。
2. 并行、汇合、分支和闭环与本次方法一致。分组边界不能替代本应明确的内部节点连接。
3. 避免穿过文字或无关框，尽量减少交叉；辅助说明不能被画成主流程必经步骤。
4. 存在循环时说明反馈内容及实际停止条件；固定预算不自动改成“迭代至收敛”。

### 生成与检查

结合本次方法和本条目的示例图组织生成提示词；可用内置图像生成工具时，将示例作为参考图输入，完成生成或编辑。用户明确要求可编辑矢量图或指定工具时遵从本次要求。工具不可用时如实说明，不能声称已生成不存在的文件。

检查生成图片中的文字、技术术语、数值、单位、箭头方向、节点连接和闭环关系，同时检查裁切、错字、拥挤和遮挡。发现实质问题时针对性修改并复核，避免修正局部时改变已经正确的其他部分。

### 输出

默认输出英文、高分辨率 PNG，只交付图片，不附绘图代码。保存到用户指定目录；新版本采用独立文件名，保留原图，除非用户明确要求覆盖。给出最终图片链接。像素尺寸按使用场景确定，不仅通过修改 DPI 元数据宣称提升了清晰度。

## 执行提示

实际绘制时同时读取本文件和示例图，不能只凭标题猜测风格。示例表达的研究内容不是通用要求；请先根据本次资料明确节点和连线，再应用风格。
