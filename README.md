skill-mention 是一个用来整理和复用常用提示词的 Codex 技能。每项功能都有固定编号，可以附上示例和模板。把常用做法收录一次，以后在对话里按编号就能找到并使用。

下载整个仓库后，把包含 SKILL.md 的 skill-mention 文件夹放到用户主目录或项目根目录下的 .agents/skills 文件夹中。然后在 Codex 对话里输入 [$skill-mention](C:\\Users\\Lenovo\\.codex\\skills\\skill-mention\\SKILL.md) 并选择该技能。

单独调用技能会显示功能目录。输入「0001」可以查看该条目的资源，输入「展开0001的提示词」可以查看全文。要执行任务，可以输入「使用0001，根据我附上的方法章节绘制论文流程图」。

0001 绘制论文流程图
根据论文的方法章节或研究流程说明，绘制适合论文使用的流程图。仓库附有一张风格示例图，默认输出英文 PNG。

0002 按投稿模板撰写论文
根据你提供的投稿模板、研究资料和目标页数，生成可编辑的论文初稿。执行此条目需要单独安装 ai-research-writing 技能。

完整功能目录见仓库里的 INDEX.md。想收录自己的提示词，可以在 Codex 中说「新增功能」，并附上功能名称、用途和提示词。
